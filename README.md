# Customer Shopping Behavior Analysis

**An end-to-end data analytics project exploring customer purchasing patterns, preferences, and behavior using Python, PostgreSQL, and Power BI.**

## 📊 Overview

Customer behavior analysis helps businesses understand what customers purchase, how they spend, and what factors influence their shopping decisions.

In this project, I analyzed **3,900 customer purchase records across 18 columns** to explore shopping patterns, customer demographics, product preferences, discount usage, and subscription behavior.

The project demonstrates an end-to-end analytics workflow, from data preparation and SQL analysis to interactive dashboard development and business recommendations.

## 🛠️ Tools & Technologies

* **Python** — Data cleaning and exploratory data analysis
* **Pandas & NumPy** — Data manipulation and feature engineering
* **PostgreSQL** — SQL-based business analysis
* **Power BI** — Interactive data visualization and dashboard development

## 🔍 Analysis Process

### 1. Data Cleaning & Exploratory Analysis

Used Python and Pandas to prepare the dataset for analysis.

* Explored dataset structure, data types, and missing values.
* Handled missing review ratings using category-level median imputation.
* Standardized column names using `snake_case`.
* Created age-group and purchase-frequency features.
* Reviewed overlapping discount and promotional-code fields.

### 2. SQL Business Analysis

Loaded the prepared dataset into PostgreSQL and investigated **10 business questions** using SQL.

Key concepts applied:

`GROUP BY` · `HAVING` · Aggregate Functions · Subqueries · CTEs · `CASE` · Window Functions · `ROW_NUMBER()`

### 3. Power BI Dashboard

Developed an interactive dashboard to present customer and purchasing insights through visualizations.

The dashboard focuses on customer demographics, purchasing behavior, product performance, discounts, subscriptions, and revenue-related trends.

## 💼 Business Questions

The analysis explores:

1. How does revenue differ by gender?
2. Do customers using discounts have above-average spending?
3. Which products receive the highest ratings?
4. How do shipping types compare?
5. How does purchasing behavior differ between subscribers and non-subscribers?
6. Is discount usage associated with customer purchasing behavior?
7. How can customers be segmented based on shopping patterns?
8. Which products perform best within each category?
9. Is there a relationship between repeat purchasing and subscription behavior?
10. How does revenue vary across customer age groups?

## 💡 Business Recommendations

The analysis can help inform business strategies such as:

* **Customer Retention:** Develop loyalty initiatives to encourage repeat purchases.
* **Subscription Growth:** Explore customer benefits that may encourage subscription adoption.
* **Discount Strategy:** Evaluate discount usage in relation to customer spending patterns.
* **Targeted Marketing:** Use customer segments to develop more relevant marketing campaigns.
* **Product Strategy:** Use product and category-level insights to support product positioning.
